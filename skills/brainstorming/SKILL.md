# Brainstorming Ideas Into Game Designs

## Overview
Turns raw prompts or open-ended requests into validated 2D game concepts through structured collaborative dialogue before any final artifacts (`README.md`, `game_balance.json`) are generated.

## Core Process (`HARD-GATE`)

1. **Explore Context & Anti-Repetition:** Inspect existing project state (`README.md`, `game_balance.json`) so previously generated sub-genres or mechanics are never repeated.
2. **Ask One Focused Question at a Time:**
   - Prefer A/B/C/D multiple-choice options plus an autonomous option.
   - Clarify target 2D sub-genre, core one-finger input feel, and 3-second visual CPI hook preference.
3. **Propose 2–3 Distinct Concepts with Trade-Offs:**
   - Present 2–3 non-clone 2D concepts.
   - Compare CPI potential, D1/D7 retention depth, and scope risks.
   - Lead with your recommended concept and apply Devil's Advocate (`Keep / Kill`) reasoning.
4. **Explicit Approval Gate (`HARD-GATE`):**
   - **STOP** and wait for the human partner to approve the chosen concept before proceeding to deep market deconstruction, MDA/Juice choreography, or `game_balance.json` generation.

## Red Flags — STOP
- Generating `game_balance.json` or full analysis reports before the user approves a concept
- Asking 4–5 questions in a single message instead of one focused question
- Offering 3 minor reskins of the same mechanic instead of genuinely distinct concepts
